## 🚗 About The Project

**THUNDERBOLT** is a futuristic electric sports car portfolio designed to present an immersive automotive experience.

The website focuses on:

- ⚡ Electric performance
- 🏎️ Sports car design
- 🔧 Automotive engineering
- 🧠 Advanced technology
- 🖥️ Digital cockpit
- 🎨 Exterior design
- 📊 Performance specifications
- 📱 Responsive web design

The goal is to combine **automotive design and modern web development** into one interactive portfolio experience.
